# Task 2 — Unemployment Analysis with Python

## Overview

This project analyzes unemployment trends in India using historical unemployment data.

The analysis focuses on regional unemployment differences, monthly trends, employment indicators, labour participation, and changes during the COVID-19 period.

## Objectives

- Analyze unemployment rates across regions
- Study monthly unemployment trends
- Compare unemployment trends across selected states
- Identify the top 10 regions by average unemployment
- Analyze relationships between unemployment, employment, and labour participation
- Compare pre-COVID and post-COVID labour-market conditions

## Dataset

The project uses the **Unemployment in India** dataset.

The dataset contains information including:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Region.1
- Longitude
- Latitude

## Analysis Performed

- Data cleaning
- Missing-value analysis
- Duplicate detection and removal
- Data type conversion
- Descriptive statistics
- Region-wise unemployment analysis
- Monthly trend analysis
- Three-state time-series comparison
- Top-10 regional unemployment analysis
- Correlation heatmap
- Pre-COVID vs Post-COVID comparison
- Identification of highest and lowest unemployment periods

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
