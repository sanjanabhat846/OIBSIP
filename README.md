## 📂 Projects

### Data Science Task 1 — Iris Flower Classification

A machine learning classification project that predicts the species of an iris flower based on its physical measurements.

**Dataset:**
- 150 flower samples
- 4 features
- 3 species: Setosa, Versicolor, Virginica

**Features:**
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

**Models Used:**
- Logistic Regression
- Decision Tree Classifier

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

**Key Finding:**
Petal length and petal width were the most discriminative features. Logistic Regression achieved the best overall F1-score of approximately 0.9666.
